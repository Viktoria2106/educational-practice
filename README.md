================================================================================
                       ДНЕВНИК ТРЕНИРОВОК
================================================================================

Краткое описание:
Веб-приложение для учёта силовых тренировок с календарём и локальным хранением.

Как запустить:
1. Скачайте и распакуйте архив
2. Откройте файл index.html в браузере

Основные функции:
- Календарь с подсветкой тренировок
- Добавление упражнений (название, вес, подходы, повторения, дата)
- Просмотр тренировок за выбранный день
- Удаление записей
- Экспорт в CSV

Системные требования:
- Любой современный браузер (Chrome, Firefox, Safari, Edge)
